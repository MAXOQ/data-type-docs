# Markdown
## Work in progress

Markdown is a human readable text format that can be mostly translated to HTML one to one, but with limited features. There are many different variations of markdown, below we show which ones support each feature.  
  
This document was made in markdown.
  
### Headers
Markdown has 6 sizes of headers corresponding to HTML's h1 - h6 elements. 
```
# header 1 (Largest header size)
## header 2
### header 3
...
###### header 6 (smallest size)
```
# header 1 (Largest header size)
## header 2
### header 3
...
###### header 6 (smallest size)
